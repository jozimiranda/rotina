# Rotina

App pessoal (PWA) para acompanhar musculação, corridas, alimentação e medidas.

- Arquivo único (`index.html`), sem build, sem servidor. Os dados ficam no aparelho (localStorage), com backup exportar/importar JSON.
- Fotos dos exercícios: [free-exercise-db](https://github.com/yuhonas/free-exercise-db) (Unlicense / domínio público).
